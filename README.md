# مشروع أوائل السادس المهني - العراق 🇮🇶

## وصف المشروع
نظام متطور وآمن للاستعلام عن أوائل الصف السادس المهني في العراق، مطور بتقنيات حديثة ومصمم خصيصاً للمستخدمين العرب.

## الميزات الرئيسية ✨

### 🎨 التصميم والواجهة
- **خطوط عربية جميلة**: استخدام خطوط Cairo، Tajawal، Almarai، وAmiri
- **ألوان متناسقة**: نظام ألوان متدرج مع تأثيرات بصرية متقدمة
- **تأثيرات الاحتفال**: كونفيتي وألعاب نارية عند عرض النتائج
- **خلفية متحركة**: جزيئات متحركة وتدرجات لونية ديناميكية
- **تصميم متجاوب**: متوافق مع جميع الأجهزة (هاتف، تابلت، كمبيوتر)

### 🔍 البحث والاستعلام
- **بحث متقدم**: البحث بالرقم الامتحاني مع التحقق من صحة البيانات
- **التحقق من تيليجرام**: نظام التحقق من الاشتراك في القناة
- **رسائل خطأ واضحة**: رسائل توضيحية باللغة العربية

### 📊 عرض النتائج
- **بطاقة نتيجة متطورة**: عرض شامل لبيانات الطالب
- **معلومات مفصلة**: الاسم، الرقم الامتحاني، المعدل، القسم، الترتيب
- **شارات الدرجات**: تصنيف تلقائي للدرجات (ممتاز، جيد جداً، إلخ)
- **إحصائيات شخصية**: مقارنة الأداء مع باقي الطلاب

### 🎯 الميزات المتقدمة
- **مشاركة النتائج**: مشاركة على فيسبوك، تويتر، واتساب
- **طباعة الشهادة**: طباعة شهادة تقدير مصممة بشكل احترافي
- **تحميل PDF**: تحميل النتيجة كملف PDF
- **إحصائيات تفاعلية**: عرض إحصائيات شاملة عن جميع الأوائل
- **تأثيرات صوتية**: أصوات احتفالية عند النجاح

### 📈 الإحصائيات
- **إحصائيات عامة**: إجمالي الأوائل، المعدل العام، أعلى معدل
- **توزيع الدرجات**: تصنيف الطلاب حسب مستوى الأداء
- **إحصائيات الأقسام**: القسم الأكثر تميزاً
- **إحصائيات شخصية**: ترتيب الطالب ومقارنة أدائه

## التثبيت والتشغيل 🚀

### المتطلبات
- Node.js 20.18.0 أو أحدث
- pnpm 10.4.1 أو أحدث

### خطوات التثبيت

1. **استخراج المشروع**
```bash
tar -xzf student-results-enhanced.tar.gz
cd student-results-project
```

2. **تثبيت التبعيات**
```bash
pnpm install
```

3. **تشغيل المشروع في وضع التطوير**
```bash
pnpm run dev
```

4. **بناء المشروع للإنتاج**
```bash
pnpm run build
```

5. **معاينة البناء**
```bash
pnpm run preview
```
